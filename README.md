# Silica Launcher

Android launcher inspired by the Sailfish OS 5 homescreen: Events | Home (covers) | Apps,
pulley menus, and an ambience (wallpaper-derived accent + light/dark).

## Build with GitHub
1. Create a free GitHub account and a new repository.
2. Upload every file in this folder (including the hidden `.github` folder), or push it with git.
3. Open the repo's **Actions** tab. **Build APK** runs on every push; you can also start it with "Run workflow".
4. When it finishes, open the run and download the `silica-launcher-debug` artifact. Unzip it and install `app-debug.apk`.
5. Press Home and choose **Silica Launcher** as the default home app.

## Events screen
Pull down on the Events page and choose "Notification access", then allow it for Silica Launcher.
If the toggle is greyed out: Settings > Apps > Silica Launcher > ⋮ > **Allow restricted settings**.
